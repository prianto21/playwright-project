**running berdasarkan spesifik test dan muncul browsernya, disini contohnya test "Successful login"
npx playwright test -g "Successful login" --headed

** running berdasarkan nama file Testnya dengan debug mode contoh disini di file loginTest.spec.ts
npx playwright test tests/loginTest.spec.ts --debug

** running biasa spesifik ke nama test
npx playwright test -g "Add product to cart"  

** running spesifik ke nama file test
 npx playwright test loginDataDriven.spec.ts --reporter=html

** untuk menampilkan report htmlnya buka di browser file reportnya di path : playwright-report/index.html
 npx playwright show-report                               


 config knowledge :
 trace: "on-first-retry", artinya trace hanya akan diambil ketika test gagal pada percobaan pertama, dan tidak akan diambil pada percobaan kedua. Jika test berhasil pada percobaan pertama, trace tidak akan diambil. Jika test gagal pada percobaan pertama, trace akan diambil dan disimpan untuk dianalisis.
